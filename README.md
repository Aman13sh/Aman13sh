## 🛠️ Featured projects

### 🦀 [Rust Relay](https://github.com/Aman13sh/relay) *(in progress)*
A relay written in Rust that connects a client machine to a host machine. The client gets the host's Git permissions while the **code stays on the client**. Changes are forwarded to the host, which pushes them to Git. I'm expanding it to production setups and to running **coding agents** on a single machine.

`Rust` `Networking` `Git` `Distributed Systems`

### 🤖 [AI-Powered Productivity Platform](https://tilted.xyz/)
A unified workspace for AI-assisted documents, presentations, spreadsheets, meeting notes and research. Includes text-to-image, image-to-video, image-to-3D, meeting summarization and deep research, deployed on GCP.

`Svelte` `Elysia.js` `TypeScript` `GCP` `AI APIs`

### 📡 Live Streaming Platform
RTMP live ingest with Cloudflare Workers uploading chunks to R2, so viewers are served from R2 with **no egress cost**. Includes authentication, secure stream management and real-time stream status.

`SvelteKit` `ElysiaJS` `TypeScript` `Cloudflare Workers` `R2` `RTMP`

### 🧱 [Micro-Frontend Architecture](https://github.com/Aman13sh/ModulararchitecutrReact)
Independently deployable Chat and Email apps with runtime module loading, a shared design system and cross-app communication using Webpack Module Federation.

`React` `TypeScript` `Vite` `Module Federation`
